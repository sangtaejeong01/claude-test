## 최대공약수와 최소공배수 계산기 🔢

초등학교 6학년을 위한 간단한 수학 계산기입니다.

### 사용 방법

1. 프로그램 실행:
```bash
python gcd_lcm_calculator.py
```

2. 화면에 나타나는 안내에 따라 두 숫자를 입력합니다.

3. 결과를 확인합니다!

### 예제

```
==================================================
🔢 최대공약수와 최소공배수 계산기 🔢
==================================================

첫 번째 숫자를 입력하세요: 12
두 번째 숫자를 입력하세요: 18

--------------------------------------------------
📊 계산 결과:
   입력한 숫자: 12, 18
   최대공약수(GCD): 6
   최소공배수(LCM): 36
--------------------------------------------------
```

### 알아두면 좋아요!

- **최대공약수(GCD)**: 두 수를 나누어떨어지게 하는 가장 큰 수
- **최소공배수(LCM)**: 두 수의 공통 배수 중 가장 작은 수

### 필요한 것

- Python 3.x 이상
