# claude-test

최대공약수(GCD)와 최소공배수(LCM)를 계산하는 Python 프로그램

## 기능

- **최대공약수(GCD)**: 유클리드 호제법을 사용하여 두 정수의 최대공약수를 계산
- **최소공배수(LCM)**: GCD를 이용하여 두 정수의 최소공배수를 계산

## 사용법

```bash
python3 gcd_lcm.py
```

프로그램을 실행하면:
1. 미리 정의된 예제들의 GCD와 LCM이 출력됩니다
2. 직접 두 개의 숫자를 입력하여 계산할 수 있습니다

## 알고리즘 설명

### 유클리드 호제법 (GCD)
두 수 a, b에 대하여 (a > b):
- a를 b로 나눈 나머지를 r이라 할 때
- GCD(a, b) = GCD(b, r)
- r이 0이 될 때까지 반복

### 최소공배수 (LCM)
- LCM(a, b) = |a × b| / GCD(a, b)

## 예제

```
숫자 1: 48
숫자 2: 18
최대공약수(GCD): 6
최소공배수(LCM): 144
```
