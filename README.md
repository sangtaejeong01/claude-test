# 최대공약수와 최소공배수 계산 프로그램

초등학교 6학년 수준에서 이해할 수 있는 최대공약수(GCD)와 최소공배수(LCM)를 계산하는 프로그램입니다.

## 기능

- **최대공약수(GCD)** 계산 - 유클리드 호제법 사용
- **최소공배수(LCM)** 계산 - 공식 사용 (두 수의 곱 ÷ 최대공약수)
- 계산 과정을 단계별로 보여주기
- 다양한 예제 포함
- 사용자 입력으로 직접 계산 가능

## 실행 방법

```bash
python3 gcd_lcm_calculator.py
```

## 사용 예시

프로그램을 실행하면 먼저 예제들이 자동으로 계산되고,
그 다음 사용자가 직접 숫자를 입력하여 계산할 수 있습니다.

```
첫 번째 숫자를 입력하세요: 12
두 번째 숫자를 입력하세요: 18

=== 12와 18의 최대공약수와 최소공배수 구하기 ===

1단계: 최대공약수 구하기
   12와 18의 최대공약수 = 6

2단계: 최소공배수 구하기
   공식: 최소공배수 = (두 수의 곱) ÷ 최대공약수
   최소공배수 = (12 × 18) ÷ 6
   최소공배수 = 216 ÷ 6
   최소공배수 = 36

✓ 결과:
  최대공약수(GCD) = 6
  최소공배수(LCM) = 36
```

## 알고리즘 설명

### 최대공약수 (GCD)
- **유클리드 호제법** 사용: 큰 수를 작은 수로 나눈 나머지로 계속 반복
- 효율적이고 빠른 계산 방법

### 최소공배수 (LCM)
- **공식 사용**: 최소공배수 = (두 수의 곱) ÷ 최대공약수
- 최대공약수를 먼저 구한 후 공식 적용

프로그래밍으로 구현한 것입니다. 코드에는 많은 주석이 달려 있어 이해하기 쉽습니다.
